Enden-Galerie

Wie spielt man?

  • 🖱️ Auf eine Option klicken, um fortzufahren.
  • ⌨️ Zahlentasten (1, 2, …) wählen eine Option direkt aus.
  • 🎮 Optionen mit diesem Symbol brauchen erst ein kleines Minispiel.
  • 🏆 Sammle alle 6 Enden – Fortschritt oben links in der Galerie.
  • ⎋ Escape schliesst geöffnete Fenster.
